## 背景 — WHY

日本語の「気軽（きがる）」から名前を取ったkigaruは、「気軽に、軽やかに」という意味です。
運勢・観相サービスを通じて、ユーザーに軽い楽しさと自己探求の体験を届けることを目標にしました。

日本を対象にしたのにも理由があります。占いや診断のコンテンツになじみがあり、SNSでシェアする文化があります。「韓国の観相学」は日本にない切り口なので、新鮮に感じてもらえると考えました。

当時書き残した本当の目標はこうです。つくるものはウェブサイトではなく、AIのシステムを運営する力だ、と。

## 成果物 — WHAT

ブースがふたつある遊び場です。ログインなしで、すぐに使えます。

- 韓国式AI顔占い
- AI自販機

2026年3月、13日間でほとんどすべてをつくりました。

| 機能 | 説明 |
|------|------|
| 観相診断 | 写真アップロード → AI解析 → 結果カード |
| 結果シェア | SNSシェア用画像生成 |
| モバイル最適化 | レスポンシブUI |

## プロセス — HOW

Next.js App Router + Static Export ベースのフロントエンドと、FastAPI バックエンドで構成しています。
Gemini Flash API を活用し、画像解析および自然言語による結果生成を処理しています。

```typescript
// Gemini Flash API 呼び出し例
const response = await model.generateContent([
  { inlineData: { mimeType: "image/jpeg", data: imageBase64 } },
  "この人の観相を分析してください。",
]);
```

## 技術的判断

| 選択 | 技術 | 理由 |
|------|------|------|
| Frontend | Next.js | Static Export + SEO最適化 |
| Backend | FastAPI | 非同期処理、Gemini API連携が容易 |
| AI | Gemini Flash | 高速レスポンス、マルチモーダル対応 |

- Geminiはサービスのエンジン、Claudeはつくるための道具、と役割を分けました。
- バックエンドは東京リージョンに置きました。使う人が日本にいるからです。
- 画像の解析と結果の解釈を2段階に分けました。コストのかかる解析だけを回数から引きます。
- 偽の結果は見せません。解析に失敗したら再試行してもらい、回数は減らしません。

## 振り返り

Gemini Flashのマルチモーダル能力を実験しながら、プロンプトエンジニアリングの重要性を実感しました。
サービスの特性上、結果の一貫性を保つことが一番の課題でした。

最後の機能追加は2026年4月8日です。サービスはいまも動いています。

止めた理由はこうです。人が本当に何を求めているのか。自分が本当に望む価値を探したいと思ってもらうには、どうすればいいのか。そして、そこにAIをどうつなげられるのか。それを、実際の会話を通して確かめに行きました。コードより、人でした。

見せたのは、親しい友だち数人だけです。
