## 배경 — WHY

일본어 "気軽(きがる)"에서 이름을 따온 kigaru는 "부담 없이, 가볍게"라는 뜻이다.
운세·관상 서비스를 통해 사용자에게 가벼운 재미와 자기 탐색의 경험을 제공하는 것을 목표로 한다.

대상을 일본으로 잡은 이유도 있다. 점·진단 콘텐츠에 익숙하고, SNS로 나누는 문화가 있다. "한국 관상학"은 일본에 없는 출처라 새롭다.

그때 적어 둔 진짜 목표는 이것이었다. 결과물은 웹사이트가 아니라, AI 시스템을 운영하는 힘이다.

## 결과물 — WHAT

가게(부스) 둘이 있는 놀이터. 로그인 없이 바로 쓴다.

- 韓国式AI顔占い (한국식 AI 얼굴 점)
- AI 자판기

2026년 3월, 13일 동안 거의 모든 것을 만들었다.

| 기능 | 설명 |
|------|------|
| 관상 진단 | 사진 업로드 → AI 분석 → 결과 카드 |
| 결과 공유 | SNS 공유용 이미지 생성 |
| 모바일 최적화 | 반응형 UI |

## 프로세스 — HOW

Next.js App Router + Static Export 기반 프론트엔드와 FastAPI 백엔드로 구성된다.
Gemini Flash API를 활용해 이미지 분석 및 자연어 결과 생성을 처리한다.

```typescript
// Gemini Flash API 호출 예시
const response = await model.generateContent([
  { inlineData: { mimeType: "image/jpeg", data: imageBase64 } },
  "이 사람의 관상을 분석해 주세요.",
]);
```

## 기술 판단

| 선택 | 기술 | 이유 |
|------|------|------|
| Frontend | Next.js | Static Export + SEO 최적화 |
| Backend | FastAPI | 비동기 처리, Gemini API 연동 용이 |
| AI | Gemini Flash | 빠른 응답 속도, 멀티모달 지원 |

- Gemini는 서비스 엔진, Claude는 만드는 도구로 역할을 나눴다.
- 백엔드는 도쿄 리전에 두었다. 사용자가 일본에 있으니까.
- 이미지 분석과 해석을 두 단계로 나눴다. 비용이 드는 분석만 횟수에서 차감한다.
- 가짜 결과는 보여 주지 않는다. 분석에 실패하면 다시 시도하게 하고 횟수는 차감하지 않는다.

## 회고

Gemini Flash의 멀티모달 능력을 실험하면서 프롬프트 엔지니어링의 중요성을 체감했다.
서비스 특성상 결과의 일관성을 유지하는 것이 핵심 과제였다.

마지막 기능 작업은 2026년 4월 8일. 서비스는 지금도 살아 있다.
