# Phase 3 — 일본어 번역 메모 (본인 검토용)

작성 2026-10-10. 대상: `content/now.ja.yaml`, `content/path.ja.yaml`, `content/projects/*/ja.md`.
한국어 원문은 같은 이름의 `ko` 파일이다. 아래는 **두 가지 이상으로 읽을 수 있어서 하나를 고른 곳**이다. 바꾸고 싶은 줄만 알려 주면 된다.

## 문체 — 결정: 사이트 전체를 です・ます로 통일 (2026-10-10, 본인)

now, path, 모든 프로젝트 페이지, UI 문자열에 적용했다.
- path 줄은 짧게 두고 끝만 정중하게 했다 (例: 「…探しに出ました。」).
- 마음속 생각을 그대로 옮긴 인용(따옴표 안 문장, 「この仕事に慣れたら…かもしれない。」 같은 생각)과 명사로 끝나는 목록·문장(体言止め)은 그대로 뒀다. 일본어 정중체 글에서도 자연스럽기 때문이다.
- 중심 문장은 「…生きられるように。それを手伝いたいです。」로 했다. 「です」를 붙이면 조금 부드러워진다. 이전처럼 「手伝いたい。」로 남기고 싶으면 알려 주세요.
- 메타 설명(siteDescription)도 같은 문장으로 맞췄다.
